## Overview

This build is an extremely tanky swordsman that is primarily used to farm PvM.

The goal with this build is to stack melee special chance, proc bleeds and disease as much as possible.

## Aspect Options

- PvM -> Death Armor & Holy Weapon
- You could sub in a different weapon for more damage and less defense

## Link Options

Thanks to the swing speed from chivalry all of our links will just continue to increase our damage. The build will feel good from the start even with little to no links.

- PvM:
    - Melee Special Chance / Special Damage
    - Damage to Bleeding/Diseased

## Codex Use

- Swords 
    - Run Aggressive for weapon special chance
    - Run Execute as finisher
    - Run Spinslash for more weapon special chance

- Parry
    - You will sit in Testudo most of the time and run Last Stand as a finisher.
    - You can use other stances situationally but Testudo offers the most DR when farming.

**Additional Codex info is in the build card**

## Equipment

This build will run full plate. Mastercrafted gear at whatever ore your budget will allow.
- Weapon: 
    - Run the fastest sword you can get, more hits = more procs.
    - (1H) Katana, Cutlass, Scimitar
- Off Hand:
    - Run a kite shield of the best ore your budget allows.
    - This is needed to enable parry.


## Farming/Gameplay

This build is a great dungeon farmer and does very well in group content in a tank/damage role. It has a ton of survivability and can still do fantastic damage.

## Additional Notes

We only use death for the extra disease ticks.

## Stats

**STR:** 100, **INT:** 25, **DEX:** 100
